# bmi-rust

[![AI Declaration Format](https://img.shields.io/badge/AI_Declaration_Format-validated-blue)](./aidecl.yaml)

The Rust specification for the CSDMS
[Basic Model Interface](https://bmi.csdms.io/en/stable/).

## Installation

Add [`bmi-rust`](https://crates.io/crates/bmi-rust) to your dependencies:

```toml
[dependencies]
bmi-rust = "0.1"
```

See the [API documentation](https://docs.rs/bmi-rust) for the complete interface.

See [bmi-example-rust](https://github.com/eWaterCycle/bmi-example-rust) for an example implementation of a BMI model in Rust.
